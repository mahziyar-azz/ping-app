# مانیتور وضعیت اینترنت ایران

## مرور برنامه
این برنامه یک ابزار تشخیصی شبکه برای ارزیابی پایداری اینترنت ایران، شبکه‌های داخلی (شبکه ملی اطلاعات)، فیلترینگ دولتی (DPI) و تحریم‌های بین‌المللی است.

نسخه جدید این برنامه به **.NET 10** و چارچوب گرافیکی **Avalonia UI** ارتقا یافته است و به صورت کاملاً بومی و کراس‌پلتفرم بر روی **لینوکس**، **ویندوز** و **مک** اجرا می‌شود.

## ویژگی‌های کلیدی
- **بررسی اتصال و تاخیر (پینگ چندبسته‌ای)**:
  1. **شبکه داخلی (NIN)**: بررسی اتصال به سرورهای داخلی و IXP بدون فیلتر.
  2. **تحریم‌های بین‌المللی (Tahrim)**: شناسایی خطاهای ۴۰۳ و ۴۵۱ ناشی از مسدودسازی رنج‌های IP ایرانی توسط کلودفلر یا ارائه‌دهندگان خارجی.
  3. **فیلترینگ دولتی (DPI)**: تشخیص مسدودسازی هوشمند، کاهش بسته‌ها (Packet Loss) و تزریق TCP RST.
  - سنجش میانگین پینگ (RTT)، نوسان زمان بسته‌ها (Jitter) و درصد افت بسته (Packet Loss).
  - انتخاب پروتکل دوگانه: پینگ ICMP یا درخواست‌های HTTP HEAD برای عبور از اختلالات لایه شبکه.

- **شناسایی هویت شبکه و مکان‌یابی (GeoIP)**:
  - نمایش نشانی IP عمومی، کشور، قاره و شرکت ارائه‌دهنده اینترنت (ISP).
  - زنجیره پشتیبان ۴ لایه برای سرویس‌های GeoIP جهت پایداری اتصال.
  - نمایش پرچم ۳۰۴ کشور به صورت کامپایل‌شده داخلی بدون نیاز به دانلود اینترنتی.

- **ثبت تاریخچه بازرسی‌ها**:
  - ذخیره خودکار ۱۰۰ رکورد آخر با قابلیت جستجو و فیلتر کردن در پنجره مجزا.

- **پایش خودکار**:
  - مجهز به تایمر پایش خودکار با شمارش معکوس قابل تنظیم.

## نحوه اجرا و ساخت

### اجرای برنامه:
```bash
dotnet run --project src/PingApp/PingApp.csproj
```

### اجرای تست‌های خودکار:
```bash
dotnet test PingApp.sln
```

### خروجی برای لینوکس و ویندوز:
```bash
# خروجی لینوکس
dotnet publish src/PingApp/PingApp.csproj -c Release -r linux-x64 --no-self-contained

# خروجی ویندوز
dotnet publish src/PingApp/PingApp.csproj -c Release -r win-x64 --no-self-contained
```
